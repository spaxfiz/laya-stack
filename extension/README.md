# 小红书自媒体运营智能打标助手 (Laya MLX Chrome 插件)

基于本地运行的 Apple Silicon MLX 加速决策模型，实时在小红书 Web 页面（`xiaohongshu.com`）上对瀑布流信息流中的每篇笔记进行全维度打标，并在卡片上直接呈现标签。支持页面滚动无限懒加载动态识别。

---

## 🏷️ 自媒体运营标签分类体系

基于小红书内容营销与自媒体运营标准，本插件会自动从 5 大核心维度对笔记进行单次前向极速分析：

1. **赛道垂直领域 (`track`)**:
   - `美妆护肤`、`穿搭时尚`、`美食探店`、`科技数码`、`职场成长`、`家居生活`、`运动健康`、`母婴育儿`、`旅游出行`、`情感心理`、`知识技能`、`摄影剪辑`
2. **选题切入形态 (`format`)**:
   - `干货教程`、`好物测评`、`避坑排雷`、`沉浸日常`、`盘点合集`、`情绪共鸣`、`热点追踪`、`经验分享`
3. **🚨 标题党与噱头风险识别 (`clickbait`) [全新升级]**:
   - 提取标题与正文片段进行语义落差对比与情绪词探测，精准标出：
     - `🚨 严重标题党` (如“倾家荡产/连夜逃离/千万别买”，正文却只是普通甚至好评的货不对板)
     - `⚠️ 悬念噱头` (过度情绪煽动或悬念引流)
     - `✨ 真实客观` (名副其实干货)
4. **商业意图与变现属性 (`is_ad` & `intent`)**:
   - 📢 **商业推广 / 软广带货** vs 🌱 **原创种草 / 个人IP**
5. **爆款潜力指数 (`viral_score`)**:
   - 1 ~ 5 分（基于标题钩子、悬念度、情绪痛点与实用价值综合评定）
6. **核心目标受众人群 (`target_audience`)**:
   - `职场上班族`、`学生青年`、`精致女性`、`家庭宝妈`、`数码极客`、`大众通用`

### 💎 高级感轻奢毛玻璃视觉设计 (Glassmorphism & Micro Capsule)
- 采用微胶囊圆润药丸形态（Pill Capsule，`border-radius: 9999px`）。
- 通透磨砂高斯模糊底色（`backdrop-filter: blur(12px) saturate(180%)`）。
- 1px 精细半透明微光边框与内嵌微光凸面效果（Glass Bevel），在白卡片与图片上均清晰高级。
- 鼠标悬浮展示精致暗色半透明气泡（Tooltip），显示置信度与标题党判定原因。

## ⚡ 安装与加载方法

1. 确保本地 Laya MLX 后端服务正在运行：
   ```bash
   # 在 laya-stack 目录执行：
   uv run laya-stack
   # 确认运行在 http://localhost:8088
   ```

2. 打开 Google Chrome 或 Edge 浏览器，访问插件扩展管理页面：
   - 浏览器地址栏输入：`chrome://extensions/`
   - 打开右上角的 **「开发者模式 (Developer mode)」** 开关。

3. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」** 按钮：
   - 选择仓库中的 `extension` 目录（例如 `laya-stack/extension`）

4. 安装成功后，扩展栏会出现 **“小”** 图标插件。

## 🎯 使用效果

1. 在浏览器中打开小红书网页版：
   👉 **https://www.xiaohongshu.com/explore**
2. 页面加载完成后，信息流中的每篇笔记卡片底部会自动注入精美的标签栏：
   - 例如：`[科技数码] [好物测评] [📢 商业推广] [🔥 4分] [👥 数码极客]`
3. **无限滚动懒加载更新**：
   - 当你向下滚动页面加载更多笔记时，内置的高性能 `MutationObserver` 自动感知新增 DOM 节点，批量向本地 MLX 服务请求标签，新卡片秒级自动打标！
4. 页面右下角有 **「⚡ Laya MLX 打标」** 浮动监控条，显示当前已标记笔记总数与启停开关。
